# Narkatiaganj Town Landing Page

## Candidate submission
Technology choice: **HTML + CSS + JavaScript**

### Why this choice?
For a single responsive landing page, vanilla HTML/CSS/JavaScript is lightweight, fast, easy to deploy on GitHub Pages, and does not require a build step or framework dependency.

## Sections included
- Hero — Discover Narkatiaganj + CTA
- About Narkatiaganj
- Places to Explore
- Culture & Lifestyle
- Local Food
- How to Reach + map link
- Why Visit Narkatiaganj
- Photo Gallery (8 images + lightbox)
- Final CTA
- Footer with navigation/contact/social links

## Run
No installation required. Open `index.html` in a browser.

For development, use VS Code Live Server if desired.

## Images
Replace the generated sample images inside `images/` with original/appropriately licensed photographs. Keep the same filenames or update the paths in `index.html`.

## GitHub Pages
1. Create a public GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and `images/`.
3. Repository → Settings → Pages.
4. Source: **Deploy from a branch**.
5. Branch: `main`; folder: `/ (root)`.
6. Save and open the generated Pages URL.

## Note
Transport, historical, landmark and contact details should be verified with reliable sources before final submission/publication.
